Solution Statement — 298 words
Clarity Dashboard: AI-Powered Career Intelligence for IBM Employees PROBLEM IBM employees spend an estimated 6–10 hours per quarter reconstructing accomplishments, manually mapping work to SuccessFactors goals, and writing self-appraisals from memory. This is not a motivation problem — it is a tooling gap. Work is being done; it is not being captured in a way that is visible, evidence-backed, or connected to the business goals it supports. The result: performance evaluations driven by recency bias, career growth that stalls not from lack of effort but from lack of visibility, and SuccessFactors data that is sparse and unverifiable. SOLUTION Clarity Dashboard is a watsonx-powered AI work log and career intelligence platform built for IBM internal use. Employees log what they worked on in under 30 seconds — or accept auto-drafted entries pulled from Jira and Slack activity. IBM watsonx foundation models then perform six automated tasks: extract skills used, write a concrete impact statement, surface measurable metrics, map the entry to the employee's SuccessFactors goals, flag any goal that is light on supporting evidence, and continuously update a personalised career gap analysis and roadmap. IMPACT — QUANTIFIED • 94% reduction in quarterly review prep time: from ~8 hours to ~30 minutes • 30 hours saved per employee per year • $1,500 annual cost saving per person at $50/hr IBM fully-loaded rate • At 10% IBM adoption (30,000 employees): $45M annual savings • At full adoption (300,000 employees): $450M annual savings potential DIFFERENTIATOR The Career Dream Engine is a private, AI-generated roadmap that compares an employee's evidenced skill profile — derived from their actual work log history, not a self-assessment form — against the competency expectations of their target role. It outputs a year-by-year milestone plan and a concrete quarterly action list, grounded in specific logged work. Critically, this makes IBM's business goals and the employee's personal career goals visibly the same thing — driving motivation, goal alignment, and retention simultaneously. TECHNOLOGY Built entirely on IBM watsonx foundation models. No third-party AI. Fully integrated with SuccessFactors goal data, Jira activity, and IBM Carbon Design System. Privacy-first: all data is private by default; managers have zero access without explicit employee consent.

Technical Statement — 312 words
Clarity Dashboard — Technical Architecture PLATFORM Clarity is a full-stack web application prototype demonstrating production-grade IBM watsonx AI integration across six distinct AI tasks. The live interactive prototype is deployed at https://tanyaprasad18.github.io/clarity-dashboard/. Frontend: IBM Carbon Design System. Backend design: Node.js/Express with SQLite. All AI tasks route through a single reusable watsonx service module — clean, auditable, and extensible. WATSONX AI INTEGRATION — 6 SPECIALISED AGENTS 1. Work Intelligence Agent — receives raw log text and optional tags; returns structured JSON: skills_used (array), impact_statement (one sentence, evidence-grounded), metrics (array, empty if not derivable). Prompt-engineered with a hard constraint: never invent metrics not supported by source text. 2. Goal Alignment Agent — compares each log entry against the employee's SuccessFactors goal list using semantic similarity; returns best-fit goal with confidence score; flags goals with zero supporting entries as deviations. User confirms or overrides all suggestions. 3. Skill Profile Builder — aggregates derivedSkills across the employee's full log history into a weighted skill profile, normalised by entry count and recency. 4. Career Gap Analyst — compares current skill profile against a seeded IBM competency ladder (IC → Senior → Staff → Director → VP) for the employee's target role; returns each competency as evidenced / partial / missing, with specific WorkLogEntry IDs as grounding evidence. 5. Roadmap Generator — inputs: current profile, target role, target timeframe, gap analysis; outputs structured JSON: year-by-year milestones + short/mid/long-term action plan. All recommendations anchored to actual gaps, not generic career advice. 6. Review Packet Generator — synthesises goal alignment data, AI-derived impact statements, and captured feedback into a SuccessFactors-formatted self-appraisal narrative; one-click generation, employee-editable before submission. DATA MODEL Core entities: User, WorkLogEntry, Goal, Feedback, CareerDream, SkillGap, Milestone, Asset, ShareGrant. All data private to the owning user by default. Share grants are explicit, scoped, and time-limited. Managers have zero default access — access control enforced at the data layer, not the UI layer. INTEGRATION DESIGN Code uses an IntegrationSource interface pattern so live SuccessFactors, Jira, and Slack API calls can replace mock data without architectural changes. Built for IBM internal deployment from day one.
